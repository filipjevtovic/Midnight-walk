## Controls

W -> move forward  
A -> move left    
S -> move backward  
D -> move right  
X -> toggle flashlight on/off  
F -> start light flickering animation  
UP -> move up  
DOWN -> move down  
ESC -> close application  
F2 -> toggle GUI on/off
